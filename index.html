Before you order

What is a HipoBuy spreadsheet?

It is a shopping shortlist that brings product links, reference prices and notes into one place. Both header buttons open CAFANS, where you can find product details and source links.

What should I check in warehouse QC photos?

Match the size label and color to your order, then check visible stitching and damage. For clothing, ask for a flat measurement photo if fit depends on a particular chest width or length. For shoes, compare both shoes and request an insole measurement if sizing is unclear.

How should I compare shipping quotes?

Compare quotes for the same destination and parcel. Check whether the line uses actual or volumetric weight and whether packing, insurance or import charges are included.
